KerbRadar — Kerbside Parking Lookup

A parking restriction lookup that answers “where can I legally park for free, here, right now?” using Digital Traffic Regulation Order (D-TRO) data. Extracts deeply nested D-TRO v3.5.1 JSON, flattens it, and loads a PostGIS medallion model (staging → curated → mart) with a star-schema core.

  • chevron_rightMapped all 3,685 fields of the D-TRO v3.5.1 schema, including the ~1,671-field provision/regulation subtree
  • chevron_rightGeometry handling across polygon, linear and directed-linear types into PostGIS
  • chevron_rightfree_parking_nearby() PostgreSQL function backed by materialised views for spatial proximity queries
  • chevron_rightBorough coverage filled from Traffweb WFS endpoints alongside the D-TRO production API and bulk export
  • chevron_rightWeekly refresh orchestrated by Airflow
